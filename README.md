# Melty Blood Actress Again Current Code Archipelago Hint Game

### Installation
Import the apworld and run the client from the Archipelago Launcher. Sign in with the slot you want to get hints for. It will connect to running instances of the MBAACC community edition, `mbaa.exe` and the most recent (as of October 10th 2026) stable CCCaster executable, named as `cccaster.v3.1.exe`. You can get cccaster and the community edition [here](concert.shib.live).

### Playing
Winning any round against a CPU or a player on netplay will give a hint. A round hint starts at a 34% chance to give a hint for a `useful` item, and improves as you get a longer win streak.

Winning a match also gives a hint, starting at a 29% chance to give a hint for a `progression` item and a 29% chance to get a `useful` item, and improving as you get a longer win streak.
